SNIP：用于子字节大语言模型训练的自适应混合精度框架

2026-11-19T06:30:00.000Z2026-11-19T06:38:23.209Z青岛

大语言模型训练里最耗算力的操作是矩阵乘法。用 FP16、BF16 跑这些 GEMM，数值稳，代价是显存和算力账单。于是有人往下压：FP8，再狠一点 FP4。压到四位，一个 GEMM 的理论吞吐能翻好几倍，问题也随之而来。

先问一个具体的问题：把模型里的某一层从 BF16 换成 FP4，训练会变差多少？

最直觉的答案是算数：比较量化前后的数值误差，误差大就说明这层扛不住。这个思路不够用。神经网络不同层对误差的敏感度差得很远，两层产生同样大小的量化误差，落到最终 Loss 上完全可以是两回事。某一层的激活值偏一点点，Loss 几乎不动；换一层，同样大小的偏差下去，Loss 明显抬起来。

所以真正要测的不是误差本身，而是模型对误差的敏感度。这就是 SNIP: An Adaptive Mixed Precision Framework for Subbyte Large Language Model Training 想解决的问题。它给每层每种量化方案估一个质量代价，再用整数线性规划（ILP）在效率约束下做全局分配。方法论的骨架集中在论文第四章，那一章只回答两个问题：量化怎么影响前向的 Loss，量化怎么影响反向传播和优化器更新之后的权重。

然后论文做了一个关键的建模动作：把这个误差当成一个小的随机高斯扰动。这只是为了能做理论分析，不是说真实量化误差服从高斯分布。做了这个假设，误差的期望行为就好算了，下面两个定理才有意义。

Theorem 4.1：用梯度估输出变化

这里的 $g$ 是任意一个从 $d$ 维映到 $m$ 维的平滑函数，$\epsilon$ 是扰动尺度，$d$ 是输入维度。定理的前提是 $\delta_x$ 服从均值 0、协方差 $\frac{\epsilon^2}{d}I_d$ 的高斯分布，且 $g$ 的梯度是 $S$-Lipschitz 的、$S \ll 1/\epsilon^2$，结论以至少 0.99 的概率成立。

公式说的事很简单：输出的变化大致等于函数的敏感程度乘以扰动的大小。梯度范数大的函数，同样的扰动会带来更大的输出偏移。

$\lesssim$ 是省略常数系数的写法，这里不是等号，也不是精确上界。

Theorem 4.2：反过来用扰动估梯度

方向掉了个头。定理 4.1 是已知梯度、估扰动造成的输出变化；定理 4.2 是观察扰动造成的输出变化、反推出梯度的范数。注意左边是梯度范数的平方，这个平方在原文里很容易漏看。

现实意义在于：有些导数算起来太贵，往输入里掺一点已知尺度的高斯噪声，看输出变动多少，就能估计出梯度有多大。第四章后面遇到二阶导时，用的正是这一招。

反向：Weight Divergence

这是第四章更难的一段，也是很多人读 SNIP 会卡住的地方。

前向那节问的是「当前这一步的 Loss 变不变」。这一节问的是「梯度变不变，梯度变了会不会导致优化器更新出不一样的权重」。两个问题不一样。某次前向 Loss 几乎不动，梯度照样可能被量化改写，参数更新的轨迹就这样慢慢偏出去。

Definition 4.4：Weight Divergence

$N$ 是层数，$W_l$ 是无量化影响时第 $l$ 层被优化器更新后的权重，$W_l’$ 是有量化影响时的权重。

分母那一项是第 $l$ 层权重的 Frobenius 范数，除它是为了消除层的规模差异。大矩阵和小矩阵的绝对差值没法直接比，取相对偏离才公平。各层算完再取平均，得到全模型的参数轨迹偏移。

这个指标补上了前向指标看不见的半边：量化有没有让模型的更新方向跑偏。

两个指标为什么要一起用

只看 $\Delta L$ 会漏掉一类情况。某层换 FP4 之后当前 Loss 几乎不动，看起来安全，但它的梯度偏得厉害，经过 AdamW 累积下去，权重会明显离开正常训练的轨迹。这种层如果单看前向指标就会被判成低风险，然后在后面几步里慢慢把训练带歪。

所以论文在第五章 5.1 把两者加权成一个质量损失：

一个管前向，一个管反向和优化器更新。

举个两层的例子。两层都在考虑上不上 FP4：

指标 Layer A Layer B
Loss Divergence 0.1% 0.2%
Weight Divergence 8% 0.5%

只看前向，A 的变化比 B 还小，A 更像该上 FP4 的那个。加上权重偏离之后结论翻过来：A 的轨迹偏移是 B 的十六倍。A 属于典型的「当前 Loss 没事，参数更新已经跑偏」，只测前向会严重低估它的风险。

第五章：先逐层估，再联合求解

第四章给了工具，第五章把它变成决策。

SNIP 不是逐层各挑一个局部最优的精度，而是把所有层放进同一个优化问题一起解。

先估每种方案的两个数

每个层、每种量化选项，都要有两个数：质量损失，记作 $q$；效率收益，记作 $e$。质量损失就用上面那个 $Q=\Delta L+\Delta W$ 估，效率收益是这层用这个选项时贡献的 FP4 FLOPs 占比。

假设三层，每层在 FP8 和 FP4 之间选，各层 FLOPs 占比都是三分之一：

层 方案 质量损失 $q$ 效率收益 $e$
Layer 1 FP8 0.1 0
Layer 1 FP4 1.0 0.33
Layer 2 FP8 0.2 0
Layer 2 FP4 5.0 0.33
Layer 3 FP8 0.1 0
Layer 3 FP4 0.5 0.33

这些数字都是编的，只为了走通逻辑，不是论文的实验数据。

Layer 1 加 Layer 2 开 FP4，质量损失 $1.0+5.0=6.0$，效率 $0.66$，达标但代价大。Layer 1 加 Layer 3 开 FP4，质量损失 $1.0+0.5=1.5$，效率同样是 $0.66$。第二个方案好得多。

ILP 做的就是这件穷举里的聪明版本：在满足效率下限的前提下，把低精度塞给不敏感的层，把高精度留给敏感的层。

流水线并行还得再加一条约束

多卡训练通常按流水线切分阶段，每个阶段的层同时在不同卡上跑。如果某个阶段被分到的都是 FP8、另一个阶段全是 FP4，快的等慢的，气泡吃掉了省下来的时间。

论文因此把 ILP 扩成带分组的背包问题：把每个流水线阶段当成一组，要求每一组自己都达到 $E_t/K$ 的效率，而不是只让整机总和达标。这样各阶段加速幅度接近，流水线才真正变快。

读的时候卡住的两个地方

这两个问题我自己读的时候反复绕了几圈，写下来省得下次再绕。

多层损失怎么合并

疑问是：前向的损失是不是把各层加起来？公式里没写多层怎么处理。

要分两件事看。第一，第四章的那个 $L$ 从一开始就是全局 Loss，不是逐层局部 Loss 的求和，所以那里没有「怎么合并」的问题，只有「扰动哪一层」的变量选择。第二，第五章确实把逐层的质量损失加起来当总成本，但那个加法发生在代理目标上，不是发生在真实 Loss 上。

论文没有完整展开怎么把全局的 $\Delta L$ 和 $\Delta W$ 精确拆成每种候选方案对应的那一项质量代价。麻烦在于某层的量化误差会顺着反向传播影响多个前面层的梯度，各层影响并不独立。所以准确的表述是：SNIP 用逐层估计搭了一个可优化的质量代理，再拿 ILP 分配精度，它算的不是所有层同时量化时的真实联合 Loss。

这条边界不影响方法可用，但读的时候得知道它在那儿。

$h(g)$ 的 $\epsilon$ 对不上

上一节说过，严格代入的稳定项是 $\epsilon\sqrt{1-\beta_2^t}$，论文写的是 $\epsilon$。训练早期 $\sqrt{1-\beta_2^t}$ 离 1 不远，差别可以忽略；但如果把 $h(g)$ 当成恒等式去做数值验证，就会在这一项上卡住。知道这是简化就够，不必当成错误。

整条链路

把第四章和第五章接起来，SNIP 是这么走的：

  1. 量化产生误差，把误差建模成小的高斯扰动。
  2. 用定理 4.1 拿梯度范数估扰动对输出的影响。
  3. 前向用梯度范数乘量化误差，估出 $\Delta L$。
  4. 反向看量化怎么改变梯度，二阶导用定理 4.2 加噪声绕过。
  5. 把梯度误差送进 AdamW 的 $h(g)$，估出权重更新的偏差。
  6. 加权得到质量指标 $Q=\Delta L+\Delta W$。
  7. 每层每个候选方案都算一遍质量损失和效率收益。
  8. 解 ILP，在效率约束下取全局最优的精度分配。

这些步骤不是一次性的。论文 Figure 6 的流程里，Step 1 到 4（收集统计、加噪、算偏差）和 Step 5 到 6（解 ILP、更新精度方案）是周期性交替的，所以精度分配会随训练阶段自己调整。论文 6.3 节的热力图也印证了逐层差异确实存在：末层 MLP 最敏感，MLP 的 down projection 次之，注意力里 V 比 Q、K 更敏感。这种结构不是套一层统一精度能摸出来的。

几个该记住的点

Frobenius 范数是全文的度量单位。 它量张量规模、量量化误差、量权重偏离，所有结论都建立在它的可比性上。

第四章的 $L$ 是全局 Loss。 只把当前层的输入和权重写成显式变量，是为了明确扰动谁，不代表损失是逐层算的。

前向和反向是两个问题。 前向问 Loss 变不变，反向问梯度变不变、权重更新偏不偏。一次前向 Loss 不动完全不保证训练轨迹没事。

$h(g)$ 的作用是把优化器塞进敏感度分析。 把 AdamW 的更新量写成一个关于当前梯度的函数，定理 4.1 才能套上去，梯度误差才换算得成权重偏差。它的分母做过简化，不是严格的 AdamW 恒等式。

$\Delta L$ 和 $\Delta W$ 缺一不可。 $Q=\Delta L+\Delta W$ 挡住了「当前 Loss 好看、参数轨迹已经在飘」这类误判，两层对比那个例子里差出十六倍。

逐层分配靠 ILP 全局求解。 逐层估出的质量损失和效率收益是输入，ILP 在效率下限的约束下找全局最优，不是每层各挑各的。

回到开头那个问题：换一层到 FP4 会怎样。SNIP 的答案是，别只看那层的数值误差，去看误差穿过整个训练流程之后留下了什么。前向留下 Loss Divergence，反向经过优化器留下 Weight Divergence，两个加起来才是这层真正的代价。有了这个代价，精度分配才谈得上优化。
